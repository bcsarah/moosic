## Perguntas Teóricas
### Semana 1
- 1.1: Qual a diferença entre as formas de declarar variáveis usando let e const?
- 1.2: O que é o DOM (Document Object Model) e qual sua importância para o JavaScript?
- 1.3: Para que serve o método document.getElementById()?
- 1.4: Qual a diferença entre .innerText e .innerHTML ao alterar um elemento HTML?
- 1.5: Por que é considerado uma boa prática colocar a tag <script></script> no final da tag <body></body> do HTML?

### Semana 2
- 2.1: O que é uma função em JavaScript e qual a vantagem de utilizá-la no código?
- 2.2: O que é um "Evento" no contexto da programação web? Dê três exemplos de eventos além do clique.
- 2.3: Qual a diferença entre declarar um evento direto no HTML (ex: <button onclick="...">) e usar addEventListener no JavaScript?
- 2.4: Como passamos parâmetros (informações) para dentro de uma função?
- 2.5: O que acontece se chamarmos uma função no JavaScript sem colocar os parênteses () ao final do nome dela em um evento?

### Semana 3
- 3.1: Para que serve a estrutura if/else em um programa de computador?
- 3.2: Qual a diferença principal entre o operador de igualdade dupla (==) e a igualdade estrita (===) no JavaScript?
- 3.3: O que acontece se a condição de um if for falsa e não houver um bloco else definido?
- 3.4: Como podemos usar os operadores lógicos && (E) e || (OU) para juntar duas condições no mesmo if?
- 3.5: Por que é necessário usar comandos como parseInt() ou Number() ao pegar a idade digitada pelo usuário em um prompt()?
